# StartUp 101: Foundations & High-Impact Workplace Habits

An interactive executive culture experience featuring 25 foundational habits detailing the exact behaviors that separate exceptional team members from average ones in high-velocity startups.

## Tech Stack
- **React 19**
- **Vite 8**
- **Tailwind CSS v4**

## Features
- 🚀 **25 Core Habits**: Master proactive communication, low-friction collaboration, and owner mindset.
- ⌨️ **Keyboard Navigation**: Use Left and Right arrow keys or spacebar to seamlessly progress through cards.
- 🎨 **Executive UI**: Clean, responsive, typography-focused design built with Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```
